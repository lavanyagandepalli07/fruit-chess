# Fruit Chess

A 3D strawberry-versus-blueberry chess game.

## Run

Open `index.html` in a modern browser with an internet connection. Three.js and
Tailwind CSS are loaded from their public CDNs.

Choose local two-player or play against the AI, select a side for an AI game,
and click a piece followed by a highlighted square to move. The game supports
check, checkmate, stalemate, castling, en passant, and automatic queen promotion.
